# Password Generator

A simple, secure, and customizable password generator application. 

## Features

*   **Customizable Length:** Choose the desired length for your passwords.
*   **Character Sets:** Include uppercase letters, lowercase letters, numbers, and symbols.
*   **Copy to Clipboard:** Easily copy generated passwords with a single click.
*   **Security:** Passwords are generated locally.

## Getting Started

### Prerequisites

*   A modern web browser
*   Node.js (Optional, if you want to run a local development server)

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/password-generator.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd password-generator
    ```
3.  If using a build tool or dev server, install dependencies:
    ```bash
    npm install
    ```
4.  Run the application:
    ```bash
    npm run dev
    ```
    *(Or simply open `index.html` in your browser if this is a static site).*

## Usage

1. Open the application in your browser.
2. Select your desired password length.
3. Choose the character types to include (Uppercase, Lowercase, Numbers, Symbols).
4. Click **Generate**.
5. Click **Copy** to save the password to your clipboard.
